# loopmem

Планировщик повторений, построенный на счётчиковой модели памяти:
память — это петли, а не записи. Вес замка = число прохождений петли,
сон режет неперепроигранные замки, вечерний реплей защищает на ночь,
TMR-подсказка во сне = k пассивных проходов.

## Чем отличается от Anki/SM-2

SM-2 держит эмпирический ease-фактор 2.5. loopmem **выводит** его из модели:
при калибровке T(c) = T0·(1+c)^β первый множитель интервала = 2.5 — совпадение
с эмпирикой, а не подгонка. Главное отличие — **сон-осведомлённость**:
планировщик знает, что ночь без реплея срезает 15% прочности, и спасает
умирающие замки вечером до сна. Дополнительно — рекомендация TMR:
3 пассивных прохода во сне дают d≈0.8 на симуляции против 0.29 у одинарного.

## Быстрый старт

```bash
pip install -e .
loopmem add "привет по-французски" "столбцы таблицы Менделеева"
loopmem review        # вечером: реплей плановых и спасение умирающих
loopmem tmr 3         # при засыпании: 3 пассивных прохода
loopmem status
```

## Модель

| Параметр | Значение | Источник |
|---|---|---|
| T0 | 4.0 ночей | симуляция даунскейлинга 15%/ночь |
| β | 1.322 | калибровка по первому множителю 2.5 |
| θ | 0.9 | целевой recall |
| ночной срез | 15% | пропорциональный даунскейлинг (de Vivo 2017) |
| TMR | k=3 | симуляция: d≈0.8 против 0.45 при k=1 |

## Монетизация

- Ядро — open source (MIT), это движок доверия и распространения.
- Pro (подписка): адаптивная калибровка T0/θ по пользователю,
  интеграция с трекерами сна (HealthKit / Health Connect),
  авто-TMR через звук в фазе медленного сна, аналитика.
- B2B: лицензия движка образованию (LMS, языковые приложения).

## Честные границы

Модель калибрована на агрегатных данных (мета-анализы спейсинга, сна, TMR).
Персональная калибровка — главный тест версии 0.2: если у реального
пользователя T0 сильно отличается от 4.0, модель обязана это выучить за 2 недели
иначе подход не лучше SM-2.
